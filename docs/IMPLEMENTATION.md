# 新阅读模块实现与参与说明

## 实际完成的开发

本次在编程助手辅助下新建 Vue 3 + TypeScript 阅读模块，替换主入口的旧阅读界面依赖。

| 功能 | 实现位置 | 核心方法 |
| --- | --- | --- |
| 题库管理 | `QuestionBank.vue`、`adapter.ts` | 检索、筛选、分页、标准 JSON 校验、自建题目增删改和导出 |
| 文章展示 | `ReadingPractice.vue`、`html.ts` | 过滤展示 HTML，桌面分栏与移动端布局，独立呈现参考内容与新答题控件 |
| 答题交互 | `ReadingPractice.vue` | Vue 管理输入状态、选项与多选数量，按题目编号保存草稿，刷新后恢复 |
| 自动判分 | `grading.ts` | 标准化答案、比对可接受写法、多选无序匹配及部分得分，不调用旧判分实现 |
| 练习记录 | `storage.ts`、`ReadingRecords.vue` | 保存会话、题目快照、答案、分数、时长与来源，回看、搜索和导出 |
| 阅读生词 | `WordDialog.vue`、`ReadingWordBank.vue` | 读取浏览器选区、按需查本地词典、保留语境与来源、收藏去重和原文标记 |
| 词汇联动 | `Study.vue`、`studySession.ts` | 新增“阅读生词库”，复用原有拼写、释义、间隔复习和错词模式 |
| 数据转换 | `prepare-reading-data.mjs` | 把原文章与题目资源提取成 JSON，保留来源信息 |

判分是个人练习用途：不评估写作或语义近似答案，也不将单篇结果换算成未经验证的 IELTS 等级。匹配题使用选择或填答控件，没有沿用旧拖拽代码。

## 沿用而非本次原创的部分

- 238 篇文章、题干、选项和原始参考答案。
- IELTS 核心词汇与本地词典数据。
- 已有单词练习、学习统计、间隔复习和基础词库功能；本次主要增加阅读生词的接入。
- 项目既有 Vue/Vite 工程基础及 Node.js 静态文件服务。

阅读与词汇模块现在由同一 Vue 应用渲染，不再依赖原 iframe 集成方式。历史文件仍留在 `public/ielts/`，不是新版阅读的运行时业务依赖。旧阅读记录没有自动迁移。

## 验证方式

- `npm test`：判分规则，包括正常答案、错误及未作答、备选写法、多选顺序、部分得分、重复及超量选项和分值汇总。
- `npm run test:browser`：在独立 Chrome 配置中检查全量内置资源适配、题库校验、参考答案得分、草稿恢复、阅读选词收藏、原文标记、提交回看、阅读生词练习、自建题目及移动布局。
- `npm run build`：数据准备、Vue/TypeScript 检查与生产构建。

这些测试核验软件处理的一致性，不代表原始试题及答案已获学科专家审定。
